# Piercer Bug & QA Tracker

Registro de bugs com severidade, passos, prints em base64 e exportação Markdown para GitHub Issues

## Funcionalidades

- **Seções principais**: Detalhes do Bug
- **Ações disponíveis**: Exportar JSON, + Reportar Bug, Excluir, Cancelar, Salvar
- **Persistência automática**: salva alterações automaticamente no navegador (`localStorage`).
- **Multilíngue**: suporte integrado com botão de troca de idioma (`PT / EN / ES`).

## Como Executar

1. Execute `start.bat` para iniciar o servidor local na porta `8118`, ou abra `index.html` diretamente no navegador.
2. Acesse `http://localhost:8118`.
